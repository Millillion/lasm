| A9 | Generated-binding mapping rules | **Decided (Jordan, 2026-11-16): the mechanical rule plus a small reviewed override table.** The first overload keeps the name, and each other one adds `With` and its first differing argument (`URLPattern.newWithOptions`). Rejected: hand-picked names everywhere (not reviewable), and no overrides (`appendWithBlobValue`). | A10 | Generated-binding mapping rules | **Decided (Jordan, 2026-11-16): mechanical names, with aliases only through the override table.** A callback type keeps its source's name (`EventListener`, `ServeHandler`, `ExportedHandlerFetchHandler`), or owner + member when the source has none (`ServeOptionsFetch`). An `abbrev` alias comes only from `overrides.json` `aliases` (A10.n), and the table has none yet. Rejected: renaming the generated types (the docs and errors would stop matching the source). PR #301, next release. | [BINDING_RULES.md](../../BINDING_RULES.md#a10-callback-type-names) | pending sign-off |
| A11 | Generated-binding mapping rules | **Decided (Jordan, 2026-11-16): the cross-tier integer table, option (b).** A source that types its integers (WebIDL, Node's `{integer}`, WIT) is followed. A TypeScript or documented `number` is `Float`, unless its name is in `overrides.json` `integers` (A11.1): `status`, `port`, `size`, `keylen`, `fd`, `limit`, `expirationTtl`, … are `Nat`, and `pid` is `Int`. Example: `crypto.randomBytes (size : Nat)`. Rejected: (a), where the same concept differs by tier, and (c), where a port is `Float`. PR #301, next release. | [BINDING_RULES.md](../../BINDING_RULES.md#a11-numbers) | pending sign-off |
| A12 | Generated-binding mapping rules | **Generated.** Every interface JavaScript can name has `I.cast? (v : Value) : IO (Option I)`, through `I.prototype.isPrototypeOf(v)` (`instanceof`). It is `none` when the runtime lacks `I`. Example: `if let some m ← MouseEvent.cast? e.val then …`. The unchecked `{ val := v }` stays for code that knows the type. Not generated for `[LegacyNoInterfaceObject]` interfaces, Deno's and Bun's declared-only interfaces, or unexported Node classes. Rejected: unchecked casts only, where a wrong cast fails later and further from its cause. PR #301, next release. | [BINDING_RULES.md](../../BINDING_RULES.md#a12-checked-downcasts) | pending sign-off |

## 0.3 `Lasm.JS.Web`

| Id | Surface | Current shape, with an example | Status |
| --- | --- | --- | --- |
| 0.3-1 | `Lasm.JS.Web` and `Lasm.JS.Web.*` (tier 1, the WinterTC Minimum Common Web API) | Generated by `scripts/bindings/generate-web.mjs` from `@webref/idl` 3.86.0 (the surface in `scripts/bindings/web-surface.json`): DOM events, messaging, streams, files, encoding, compression, URL, fetch, Web Crypto, performance, timers, console, `WebAssembly`. Mapping (docs/JS_BINDINGS.md, "Standard bindings"): interfaces are handle structures over `Value`, Promise results `Async`, nullable values `Option`, dictionaries structures, unions inductives, callbacks `X.ofFn`/`X.ofSyncFn`. Example: `let res ← fetch (.usvString "https://example.com")`, `SubtleCrypto.digest (self : SubtleCrypto) (algorithm : AlgorithmIdentifier) (data : ByteArray) : Async ByteArray`. | decided, pending sign-off |
| 0.3-2 | `Lasm.JS.Web.Browser` (the browser tier) | The same generator and source, surface `scripts/bindings/browser-surface.json` (`scripts/bindings/web-browser.mjs`): `Lasm.JS.Web.Dom`, `Html`, `Css`, `Geometry`, `UiEvents`, `Canvas`, `WebSocket`, plus all of tier 1. Replaced `Lasm.Web` in 0.7.0 (A51). | decided, pending sign-off |
| 0.3-3 | `Lasm.JS.Web.Support` | Hand-written helpers the generated code calls, all public: `Record α`, `Support.optional`, `Support.args`, `Support.fields`, `Support.arrayBufferBytes`, `Support.typedArray`, `Support.getGlobal`, …. Open: whether they stay public or move to an internal namespace. | open |
| 0.3-4 | Generated-binding mapping rules (all tiers) | Overload names (`serve`, `serveWithOptions`), callback type names, number typing, checked downcasts, and the reviewed override table Jordan decided on 2026-11-16: decided in A9–A12 and [BINDING_RULES.md](../../BINDING_RULES.md) (PR #301); the table is `scripts/bindings/overrides.json`. | decided, pending sign-off |
| A9.1 | Lasm.JS.Web, `FormData` | `FormData.appendWithBlobValue` → `FormData.appendBlob`, and `FormData.setWithBlobValue` → `FormData.setBlob`, through the override table. Example: `form.appendBlob "file" blob (some "x.txt")`. Why: the mechanical name repeats the IDL argument name. Rejected: keeping it, or `appendFile`, which is wrong because the spec takes any `Blob`. Breaking; migration in docs/release/next/binding-rules.md. PR #301, next release. Detail: [BINDING_RULES.md](../../BINDING_RULES.md#a9-overload-names). | pending sign-off |
| A11.1 | Every tier whose source does not type integers (Node, Deno, Bun, Cloudflare) | The integer table: the rows in `scripts/bindings/overrides.json` `integers`. Each row has a name (or `Owner.name`), `Nat` or `Int`, and a reason. Rows: HTTP `status` and `statusCode`; `port`; sizes and lengths (`size`, `byteLength`, `length`, `keylen`, `outputLength`, `highWaterMark`, `maxBuffer`, `maxmem`, `maxRequestBodySize`); counts (`count`, `limit`, `iterations`, `pendingRequests`, `tcpBacklog`); scrypt's `cost`, `blockSize`, `parallelization`, `N`, `r` and `p`; `fd`, `uid`, `gid`, and `pid` (`Int`); and whole-unit times (`timeout`, `idleTimeout`, `expirationTtl`, `expiration`, `cacheTtl`). Effect today: Node's `crypto.randomBytes`, `pbkdf2`, `hkdf`, `scrypt`, `process.kill`, `FileHandle.fd`, the `child_process` options and the stream options take `Nat`/`Int`. Breaking; migration in docs/release/next/binding-rules.md. PR #301, next release. Detail: [BINDING_RULES.md](../../BINDING_RULES.md#a11-numbers). | pending sign-off |
| 0.3-5 | `Request`/`Response` conversion helper | Every server converts by hand (about 20 lines, as the `fetch` template's `serveNode` does). A13. | open |
