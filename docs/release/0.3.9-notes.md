# Lasm 0.3.9

A bug-fix release. Upgrade with `npm install -D @lasm/cli@0.3.9`.

## Fixes

- **`Request.path` resolves `.` and `..` the same way on every platform (#27).**
  - **The bug:** before 0.3.9, whether `/hello/../hello/Ada` reached a Lasm.Fetch handler as written or already resolved depended on the platform.
  - **The fix:** `req.path` is now resolved the way a browser resolves a URL path (the WHATWG URL rules), on every platform:
    - `/hello/../hello/Ada` is `/hello/Ada`;
    - escaped dots (`%2e`, `%2E`) count as dots;
    - `\` counts as `/`;
    - a `..` above the root stays at the root.
  - **The proof:** `req.segments` never contains `.` or `..`. Lean checks this as `Request.segments_no_dot_segments`, so a handler that maps segments to files or keys can't reach a parent.
  - **Tests:** the target-equivalence corpus has new cases for encoded, mixed and above-root dot segments and for backslashes. The cases run on every target.
  - See [FETCH.md](../FETCH.md).
- **A `://` in the query no longer breaks routing (#76).** A request such as `/authorize?redirect_uri=http://localhost/cb`, with an unencoded URL in its query, had its whole URL read as the path, so no route matched. The path is now taken before the query and fragment. Lasm.Fetch checks this with build-time tests, and the target-equivalence corpus has a new case for it. Found while building the Porter example app.
- **Lasm.JS errors are no longer wrapped twice (#51).** Two kinds of failure reached Lean as `Error: TypeError: …` instead of `TypeError: …`:
  - a settled JavaScript value that couldn't be converted;
  - an awaited promise that rejected with a Lasm.JS error.

  Fixed on Node and on the edge targets. Found by mutation testing.
- **The dev build service lets the process exit (#49).** `createBuildService({ unref: true })`, which the Vite plugin uses, kept Node running after the work finished. Found by mutation testing.

## Testing (no change to how programs build or run)

- **Mutation testing** (Stryker) of the critical JavaScript: the host bridge, the Lasm.UI applier, the build service, the edge glue, notices, the link driver and the target links.
  - Every module now scores above 80%.
  - CI fails if a score drops.
  - Scores and method are in [TESTING.md](../TESTING.md).
- **Two more example apps, each with proofs and outside checks:**
  - **[Ledger](../../examples/ledger)** follows TigerBeetle's data model. TigerBeetle itself is the differential oracle.
  - **[Folio](../../examples/folio)**, a Markdown site generator, passes the CommonMark spec suite and matches `commonmark.js` byte for byte.
- **Conduit:**
  - Concurrent reads no longer see half-done writes on Node and Bun (#59).
  - Its two recorded gaps are fixed and proved.
