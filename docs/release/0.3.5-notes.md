# Lasm 0.3.5

A documentation and example release, so that the npm page shows the current
README. Upgrade with `npm install -D @lasm/cli@0.3.5`. The compiler, the runtimes
and the library are unchanged from 0.3.4: nothing changes in how programs build
or run.

## Documentation

- **Support Lasm.** The README and `llms.txt` have a section on sponsoring the
  project through GitHub Sponsors.
- **README for Conduit.** The README now features Conduit's complete app, the
  Lean frontend and the proved theorems, as the flagship example.

## Conduit (`examples/conduit`)

- **The frontend is written in Lean** with `Lasm.UI`, rendered on the server and
  hydrated in the browser. It passes the official RealWorld end-to-end suite
  without retries: on Node with Chromium, Firefox and WebKit, and on Workers and
  Bun with Chromium.
- **Proofs.** Theorems about the code the server runs and about the browser app
  and its Markdown are checked in CI (`examples/conduit/PROOFS.md`).
- The example uses `@lasm/cli` 0.3.4 or later.

## CI

- `fullstack.yml` uses the pinned edge runtime from its release instead of
  rebuilding it. The rebuild was being stopped by the resource guard on
  standard runners. `workers.yml` still rebuilds it and checks it against the
  catalog.
