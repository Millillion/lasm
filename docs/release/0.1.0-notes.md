# Lasm 0.1.0 (draft release notes)

Lasm compiles ordinary Lean 4.35.0 programs to WebAssembly that runs in Node. This
is the first npm release: `npm install @lasm/cli` (bin `lasm`) or
`npx @lasm/cli init my-app`. You need only Node 24 or newer and npm; Lasm brings
Lean, Lake and its build tools itself.

## Highlights

- `lasm Main.lean` builds and runs; `lasm build Main.lean` writes a self-contained
  `dist/` that needs only Node. Lake projects and their dependencies work.
- `lasm init` with templates `plain`, `express`, `hono` and `std-http`, a Dockerfile,
  and `--deploy lambda` for an AWS Lambda container image.
- `import Lasm.JS`: call npm packages and Node APIs from Lean with typed bindings,
  promises as Lean tasks, and Lean request handlers in Express or Hono. npm
  dependencies are deployed in `dist/node_modules`.
- Lake projects with C code build without a system C compiler (Lean's clang and C
  library headers are provided; macOS needs the Xcode Command Line Tools SDK).
- Builds from any supported machine also run on Linux x64/arm64 (glibc 2.28+).

## Supported

Compiler and apps: Linux x64/arm64, macOS x64/arm64, Windows x64; Node 24+
(tested: Node 24.0.0, 24.22.1 and 26.12.1 on Linux; 26.12.1 everywhere).
Deployment: Docker/Kubernetes images (Debian, Ubuntu, Amazon Linux 2023), AWS
Lambda container images, and container recipes for Cloud Run, Fly.io, Railway,
Render and Heroku. Every claim names the CI job that backs it in the
[README](../../README.md#supported-platforms); hosted platforms are tested only
through their local images and emulators.

## Validation

Before release, the candidate passed the full launch gate: the upstream
runtime-capable Lean 4.35.0 suite and 19 ecosystem projects on all five targets,
with zero regressions against the previous accepted release. It also passed three
back-to-back cold installations, server robustness and fault tests, the release
benchmarks and an npm rehearsal. Big-number results match native Lean.
Details, run IDs and the classified non-passes: [0.1.0-gate.md](0.1.0-gate.md).

## Known limitations

Ahead of time only (no run-time elaboration, evaluation, plugins or Lean as a
library beyond data), no prebuilt native libraries, no Windows ARM64,
Alpine/musl or edge isolates yet, at least 512 MB of memory per app,
waiting Lean handlers bounded by Lean's worker threads, and arbitrary-precision
arithmetic beyond a few hundred digits that is slower than GMP (at 10,000 digits
multiplication about 5× and `Nat.gcd` about 60×). Full list:
[README, Known limitations](../../README.md#known-limitations).
