# The wasi-http component template (third-party contents)

`proxy-template.wasm` is made by `scripts/wasi/make-component-template.mjs`
(CI, pinned wasm-tools 1.262.0) and is spliced into every `lasm build --target
wasi-http` component (src/wasi/wasi-component.mjs). Besides a placeholder for
the program's own module it contains:

- Wasmtime's `wasi_snapshot_preview1.proxy.wasm` adapter, unmodified, from the
  Wasmtime v49.0.4 release (SHA-256
  `59c393eeaecf0d7f1c71af71b27d588ab21e9f159f67018ce4e036a565b097bb`; source:
  https://github.com/bytecodealliance/wasmtime/tree/v49.0.4/crates/wasi-preview1-component-adapter),
  Copyright the Bytecode Alliance contributors, licensed under the Apache License
  2.0 with LLVM Exceptions. It is Rust code and may contain parts of Rust's
  `core` library (MIT OR Apache-2.0; Lasm uses the Apache-2.0 option).
- Canonical ABI glue and type information generated by wasm-tools 1.262.0
  (`wit-component`) from the WASI 0.2.12 WIT files (Apache-2.0 WITH
  LLVM-exception, `scripts/wasi/wit/deps/`).

The licence text is in [LICENSE](LICENSE) (Wasmtime's `LICENSE` at v49.0.4,
byte-identical to wasm-tools' `LICENSE-Apache-2.0_WITH_LLVM-exception`). Wasmtime
has no NOTICE file. Every wasi-http build's `THIRD_PARTY_NOTICES.txt` and its
embedded `lasm.notices` section carry this text (src/notices.mjs).
